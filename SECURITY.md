## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us responsibly. 

**Do not open a public issue on GitHub.** Instead, follow these steps to report the issue:

1. **Email us**: Contact the project maintainers directly by sending an email detailing the vulnerability.
2. **Details to include**:
   * A clear description of the vulnerability and its potential impact.
   * Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
   * Details of the environment (OS, Node version, browser, etc.) where it was verified.
3. **Response timeline**:
   * You can expect an initial acknowledgement of your report within **48 hours**.
   * We will provide updates on the investigation progress every **3 to 5 days** until resolved.
4. **Resolution**:
   * If accepted, we will coordinate a patch and release a security update.
   * If declined, we will provide a detailed rationale.
